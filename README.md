# Лабораторна робота №2: Реалізація REST API ⚽️

**Мета:** Навчитися створювати серверну частину застосунку з чіткою структурою API.

## 📌 Опис завдання
Це завдання — це бекенд для системи управління футбольною статистикою. Розроблено на мові Python з використанням фреймворку FastAPI. 


## 🗂 Сутності та зв'язки
Реалізовано 3 сутності з ієрархічною вкладеністю:
1. **Ліга (League)** — базова сутність.
2. **Команда (Team)** — має зв'язок із конкретною лігою (`league_id`).
3. **Матч (Match)** — містить посилання на дві команди-учасниці.

## ✅ Виконані завдання (REST API)
- **CRUD:** Повністю реалізовано операції Create, Read, Update, Delete.
- **Дотримання HTTP-методів та кодів:**
  - `GET` — отримання списку або одного елемента (успішний код `200 OK`).
  - `POST` — створення нового елемента (код `201 Created`).
  - `PUT` — оновлення існуючого елемента за ID (код `200 OK`).
  - `DELETE` — видалення елемента за ID (код `204 No Content`).
  - **Обробка помилок:** Якщо елемент не знайдено, сервер коректно повертає `404 Not Found`.
- **Додатковий функціонал (у GET-запитах):**
  - **Пагінація:** реалізована через параметри `skip` та `limit`.
  - **Фільтрація:** пошук команд за мінімальним рейтингом.
  - **Сортування:** сортування списку команд за силою/рейтингом.
