# Лабораторна робота №2: Реалізація REST API ⚽️

**Мета:** Навчитися створювати серверну частину застосунку з чіткою структурою API.

##  Опис завдання
Це завдання — це бекенд для системи управління футбольною статистикою. Розроблено на мові Python з використанням фреймворку FastAPI. 


## Сутності та зв'язки
Реалізовано 3 сутності з ієрархічною вкладеністю:
1. **Ліга (League)** — базова сутність.
2. **Команда (Team)** — має зв'язок із конкретною лігою (`league_id`).
3. **Матч (Match)** — містить посилання на дві команди-учасниці.

##  Виконані завдання (REST API)
- **CRUD:** Повністю реалізовано операції Create, Read, Update, Delete.
- **Дотримання HTTP-методів та кодів:**
  - `GET` — отримання списку або одного елемента (успішний код `200 OK`).
  - `POST` — створення нового елемента (код `201 Created`).
  - `PUT` — оновлення існуючого елемента за ID (код `200 OK`).
  - `DELETE` — видалення елемента за ID (код `204 No Content`).
  - **Обробка помилок:** Якщо елемент не знайдено, сервер коректно повертає `404 Not Found`.
- **Додатковий функціонал (у GET-запитах):**
  - **Пагінація:** реалізована через параметри `skip` та `limit`.
  - **Фільтрація:** пошук команд за мінімальним рейтингом.
  - **Сортування:** сортування списку команд за силою/рейтингом.


# Лабораторна робота №3: Простий Frontend-застосунок (Football API & Dashboard) 

Цей проект складається з двох частин: REST API бекенду на **FastAPI** (з Лабораторної №2) та клієнтського застосунку на **React** (Лабораторна №3). Проект дозволяє переглядати список футбольних команд, додавати нові та має базову систему авторизації.

##  Основний функціонал

* **Бекенд (FastAPI):**
  * REST API для роботи з сутностями (Команди, Ліги, Матчі).
  * Ендпоінти для реєстрації та авторизації (`/login`, `/register`).
  * Налаштований CORS для роботи з клієнтським застосунком.
* **Фронтенд (React + Vite):**
  * **Авторизація:** Сторінки входу та реєстрації.
  * **Спільний стан (Global State):** Збереження JWT-подібного токена за допомогою Context API та `localStorage`.
  * **Навігація:** Базова маршрутизація через `react-router-dom` (мінімум 3 сторінки).
  * **Обробка помилок:** Перехоплення помилок від API (наприклад, невірний логін).
  * **UI/UX:** Сучасний темний інтерфейс (Dark Mode).

##  Технологічний стек

* **Бекенд:** Python, FastAPI, Uvicorn, Pydantic.
* **Фронтенд:** React, Vite, React Router, Axios, Context API.

##  Лабораторна робота №4: Тестування та Скрапінг

У цій лабораторній роботі було реалізовано комплексне тестування API та автоматизований збір даних.

### 1. Unit та Інтеграційні тести (Pytest)
Написані тести для перевірки базового функціоналу API (CRUD) та системи авторизації. 
**Покриття коду (Code Coverage) складає 85%**.
**Запуск:** `python -m pytest tests/ --cov=main --cov-report=term-missing`

### 2. Навантажувальне тестування (Locust)
Реалізовано складний сценарій: віртуальний користувач створює нову команду і одразу робить GET-запит на її отримання за згенерованим `id`.
**Запуск:** 1. `uvicorn main:app --reload`
2. `locust` (в іншому терміналі)
3. Відкрити `http://localhost:8089`

### 3. Автоматизований збір даних (Selenium)
Скрипт відкриває браузер, проходить авторизацію та автоматично зчитує текстові дані.
**Запуск:** `python scraping/scraper.py`
